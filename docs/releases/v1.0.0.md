# EndoscopeViewerWIN 1.0.0

The tiny Wi-Fi camera now has an actual Windows installer. “Android only” remains a suggestion.

## Install

Download **EndoscopeViewerWIN-1.0.0-windows-x64-setup.exe**, run it, choose a folder, and launch EndoscopeViewerWIN from the Start menu. Optional desktop shortcut and Windows uninstaller included. Installs for the current Windows account; administrator access is not required. Choose F: or another drive in the installer if preferred.

Requires **64-bit Windows 10 (1809+) or Windows 11**, plus a Wi-Fi adapter for the camera hotspot. **Python, Tkinter and Pillow are bundled.** Do not run Setup.cmd or install Python for the packaged release.

Prefer portable? Extract **EndoscopeViewerWIN-1.0.0-windows-x64-portable.zip** completely, then run EndoscopeViewerWIN.exe. Keep its `_internal` folder alongside it.

## Included

- Live MoLink-family UDP/JPEG camera video.
- Camera hotspot discovery, automatic Wi-Fi joining and connection verification.
- Rotate, mirror, freeze, digital zoom and PNG snapshots.
- MP4 recordings use the zoom, rotation and mirror settings selected when recording starts.
- 40 camera-control entries, with explicit replies, timeouts and errors.
- MIT viewer source and bundled runtime notices.

**MP4 recording requires FFmpeg installed separately and available on PATH.** Optional RTSP diagnosis also requires ffplay. Neither FFmpeg executable is bundled. Live JPEG viewing, controls and snapshots work without FFmpeg.

Only the developer's **LIMINK / Jetion-hotspot** unit has been verified. Other HD WIFI / MoLink-family models are candidates, not a brand-wide compatibility promise. Some shared-library controls receive no response on this unit.

## Saved data and updates

Installed/portable builds keep preferences, default captures and recordings in a **data** folder beside the executable. The installer retains that folder during uninstall. Close the app before updating; run the newer installer into the same folder.

This first release is **unsigned**. `SHA256SUMS.txt` contains SHA-256 checksums for the installer and portable ZIP. The release contains no APK, vendor library, personal preferences or private camera captures; public README media remain in the source repository.

## Release verification

- 14 protocol, Wi-Fi and recording-view tests passed in the isolated build environment.
- Standalone, installed and extracted portable runtimes passed Tcl/Tk/Pillow checks with Python absent from PATH.
- Installer/uninstaller round trip passed; user data was retained.
- Installed executable automatically found the camera and displayed live 1280 × 720 video on the tested LIMINK unit; upright rotation and 2× zoom were checked.
- Portable ZIP integrity and exclusion of preferences/private media were checked.
